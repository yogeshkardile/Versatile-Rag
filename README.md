# Versatile RAG

The project is organized into exactly three top-level folders:

- `Application/` — FastAPI backend, React frontend, tests, configuration, and
  application documentation.
- `Experiments/` — dataset audit, frozen retrieval evaluations, Stage 3
  generation evaluation, provenance, results, and reproduction metadata.
- `IEEE/` — complete Markdown and IEEE LaTeX paper drafts, bibliography,
  methodology, literature review, and submission materials.

Historical experiment sources remain preserved in the session-state archive.
The migrated Phase 5, Phase 5.1, Phase 5.2, and Stage 3 copies are not
regenerated by this organization step.
